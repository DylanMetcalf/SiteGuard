What's left to launch

The software is finished and tested (195 automated tests). What remains are accounts and settings only the owner can create — about 2 hours, plus waiting for the domain and email checks. Full click-by-click instructions are in docs/GO_LIVE.md.

  1. Merge the work on GitHub. Open the pull request and click Merge pull request.
  2. Create a Render account (render.com, sign up with GitHub) and add a card.
  3. Create COMVERA on Render in one click: New → Blueprint → choose the repository. Enter your email for PLATFORM_ADMIN_EMAILS and SUPPORT_EMAIL. Wait until it shows Live.
  4. Sign up as yourself and confirm your email (from Render's log until email is set up). Check that More → Platform appears.
  5. Make the lifetime promo code for family and friends: More → Platform → Promo codes (100% off, no end date, limited uses).
  6. Buy the domain (e.g. comvera.co.za, about R99/year), add it in Render, add the CNAME record at the registrar, then set APP_URL.
  7. Set up email with Resend: verify the domain, create an API key, set SMTP_URL and EMAIL_FROM in Render. Needed for confirmations, resets, invitations, reminders and Exchanges.
  8. Optional — AI: buy $10–$20 credit at console.anthropic.com and set ANTHROPIC_API_KEY. Everything works without it.
  9. Uptime check: add the GitHub variable COMVERA_URL so you are emailed if the site goes down.
  10. Backups: confirm Render's daily database backups and disk snapshots; do the monthly restore test.
  11. First real test: sign up your parents with the promo link, build a safety file, try an Exchange (see GO_LIVE §7).

Running cost

About R265 per month for the beta: Render web service ≈ R126, database ≈ R108, document storage ≈ R23, domain ≈ R8, email R0 (free tier), monitoring R0. AI is optional, roughly R50–R400 a month for a small beta.
